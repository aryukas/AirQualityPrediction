🌏 India Air Quality Tracker

A web application that monitors and predicts air quality across Indian cities, providing users with real-time AQI data, historical trends, and 7-day forecasts.
Built with Flask, Tailwind CSS, and Chart.js for a seamless and responsive experience.

Features
1.Select a city to view its air quality index (AQI) and pollutants.
2.Shows "historical AQI trends" with interactive charts.
3.Predicts AQI for the "next 7 days" Historical AQI Trends.
4.Color-coded cards for pollutants based on severity Pollutant levels are displayed using color-coded severity indicators (e.g., green = good, red = hazardous).
5.Responsive design for laptops and desktops.


 Tech Stack

1.Frontend: HTML, Tailwind CSS, Chart.js  
2.Backend: Python, Flask  
3.Data: Air quality index and pollutants for Indian cities
